# 📒 مفكرتي

تطبيق أندرويد لتدوين الملاحظات اليومية بشكل مفصل ومنظم مع تذكيرات أصلية (تعمل حتى مع إغلاق التطبيق).
يُبنى ملف APK تلقائيًا عبر GitHub Actions.

## طريقة الاستخدام

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا باسم `mufakkirati`).
2. ارفع كل محتويات هذا المجلد إلى المستودع (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** وانتظر انتهاء البناء (5 إلى 10 دقائق). يمكنك أيضًا تشغيله يدويًا من **Build APK ← Run workflow**.
4. حمّل الملف `mufakkirati.apk` من قسم **Releases** (على يمين صفحة المستودع) أو من **Artifacts** داخل تشغيل البناء.
5. ثبّت الملف على الهاتف، وفعّل «التثبيت من مصادر غير معروفة» إذا طُلب منك.

## ملاحظات
- عند أول تشغيل اسمح بالإشعارات، وللتذكير في الوقت بالضبط اسمح بـ «المنبهات والتذكيرات» من إعدادات التطبيق.
- بعض الهواتف (شاومي، هواوي، أوبو...) توقف التطبيقات في الخلفية؛ فعّل «التشغيل التلقائي» وأزل قيود توفير البطارية للتطبيق.
- النسخة الاحتياطية في التطبيق تُنسخ كنص إلى الحافظة، والصقه في مكان آمن.
- الملف المبني هو نسخة debug صالحة للتثبيت المباشر. للنشر في Google Play تحتاج نسخة موقّعة (release).
